Display steuern

Öffnungsstatus und Nachricht über den vorhandenen GitHub-Workflow ändern.

Mit GitHub anmelden

Sie benötigen ein GitHub-Konto mit Schreibberechtigung für das Repository GOben-e-fit/busching-display. Anmeldung und Berechtigungsprüfung erfolgen bei GitHub.

Display-Steuerung auf GitHub öffnen

Fehlt dort die Schaltfläche „Run workflow“, prüfen Sie Ihre GitHub-Anmeldung und lassen Sie die Repository-Berechtigung von der Projektverwaltung prüfen.

Status ändern

  1. Den Workflow Update Display Status über den Link öffnen.
  2. Auf Run workflow klicken und den Branch main auswählen.
  3. Die gewünschten Werte auswählen und mit Run workflow starten.
  4. Den erfolgreichen Abschluss des Laufs abwarten und anschließend die Displayanzeige prüfen.
Display mode (open/closed/warning)
open = geöffnet · closed = geschlossen · warning = Hinweis.
Custom message to display (optional)
Eigene Hauptnachricht für das Display. Das Feld kann leer bleiben.
Custom subtitle (optional)
Zusätzlicher Text unter der Hauptnachricht. Das Feld kann leer bleiben.
Enable auto schedule
true aktiviert den automatischen Zeitplan; false deaktiviert ihn. Bei aktivem Zeitplan kann der nächste geplante Lauf den manuell gewählten Status ändern.
